# Billcoin

Billcoin is a proposed independent proof-of-work cryptocurrency. This repository is currently at the planning stage.

## Current status

- [x] Initial repository created
- [x] Draft monetary parameters documented
- [ ] Select and pin an upstream codebase release
- [ ] Build upstream software without modifications
- [ ] Run baseline tests and document results
- [ ] Review Billcoin consensus design before implementation

## Draft parameters (not implemented)

- Maximum supply: 21,000,000 BIL
- Smallest unit: 0.00000001 BIL
- Target block interval: 10 minutes
- Initial subsidy: 50 BIL
- Halving interval: 210,000 blocks
- Proof of work; algorithm not selected
- Development reserve: proposed 5% of each subsidy, pending consensus design review

These are proposals only. Nothing in this repository should be treated as a functioning cryptocurrency or production-ready code.
